# История изменений (Changelog)

Все заметные изменения **Eternum Launcher** и **Eternum Modpack Manager** фиксируются в этом файле и автоматически прикрепляются к релизам на GitHub и GitLab.

## [v1.4.0] — 2026-11-28

### Новое
- **Сплеш-скрин при запуске**: плавное появление логотипа по центру с последующим выездом названия **ETERNUM LAUNCHER** из-за логотипа и мягким переходом к главному экрану через блюр.
- **Плавные blur-анимации и переключение табов без скачков**:
  - Скользящий индикатор табов (`Вход через Ely.by` / `Офлайн режим`) и фиксированная сцена карточек — элементы интерфейса больше не прыгают при смене вкладок и состояния входа.
  - Переходы экранов, карточек настроек, консоли и уведомлений оформлены с плавным эффектом размытия (`blur`) и масштабирования.
  - Всплывающие уведомления перенесены в правый нижний угол, а все скроллбары стилизованы под тёмную фиолетово-бирюзовую тему лаунчера.
- **Dynamic Island для загрузки Java**: компактная полоса-островок встроена в шапку лаунчера и показывает прогресс скачивания и распаковки Eclipse Temurin поверх любого экрана, не мешая соседним элементам.
- **Полноэкранный экран настроек**: переработанное меню с раздельными карточками (RAM, зеркала GitHub/GitLab, встроенная таблица версий Java в стиле Prism Launcher, каталоги и диагностика).
- **Изменяемый размер окна и консоли**: окно лаунчера можно свободно растягивать (`min 820×580`), а высоту консоли можно менять перетаскиванием верхней границы (с сохранением размера).
- **Улучшенная консоль лаунчера**: свободное выделение текста и стектрейсов (`Ctrl+C` или **📋 Копировать**), сохранение логов в `~/.eternum/logs/launcher-*.log`, открытие папки логов и быстрая очистка.
- **Автоматический Changelog в релизах**: каждый тег на GitHub Releases и GitLab Releases теперь публикуется с подробным описанием изменений.

### Исправления
- Предотвращена повторная загрузка Java, если совместимая версия (например Java 21) уже установлена — и в интерфейсе, и на уровне бэкенда.
- Исправлено «зависание» прогресс-бара запуска на ~86% после установки Java из настроек (поток прогресса Java полностью отделён от прогресса запуска игры).

## [v1.3.3] — 2026-11-27

### Новое и исправления
- Автоопределение версий Java в системе в стиле Prism Launcher и строгая проверка совместимости перед запуском Minecraft.
- Автоматическая установка Eclipse Temurin нужной версии (Java 8 / 17 / 21 / 25) по версии Minecraft.
- Исправлен classpath при запуске NeoForge 1.21.1 (устранено дублирование клиентского `1.21.1.jar` на BootstrapLauncher).
- Добавлена поддержка **Windows 7 x64 (без WebView2)** для лаунчера и менеджера сборки через встроенный локальный WebUI-режим (`--web`).
