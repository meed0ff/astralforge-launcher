3. Доступ для загрузки на GitHub (токен сохраняется только на этом ПК)
Для публикации на сервер укажите токен (Collaborator или токен только для этого репозитория).
Как выдать доступ только нужным людям (например, подруге):
  1. На GitHub откройте meed0ff/eternum-modpack → Settings → Collaborators → Add people и добавьте её аккаунт с правами Write.
  2. Она создаёт у себя Fine-grained token (github.com/settings/tokens?type=beta) с доступом Only select repositories → eternum-modpack и правом Contents: Read and write (или вы создаёте такой токен только для этого репозитория и передаёте ей).
  3. Она вставляет токен в поле выше — программа запоминает его локально и больше не спрашивает.
